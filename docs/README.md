# CRules 文档

CRules 接收 C# 风格的函数体、输入签名和返回类型，生成可重复执行的 executable。它通过 DynamicExpresso 的公开 API 解析表达式，再组合标准表达式树；没有 fork 上游，也不使用 Roslyn 在生产运行时编译脚本。
