配色生成意图为石墨灰 `#303644`、琥珀橙 `#F59A24`，生成图为光栅稿，实际像素包含抗锯齿及生成偏差。当前 README 使用正式 PNG。矢量源和单色版本可在后续需要时制作。

产品口号：**以不变应万变**。含义：以一种规则配置方式，应对万变的规则配置需求。
