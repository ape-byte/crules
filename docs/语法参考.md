# 语法参考：CRules Syntax 1.0

CRules 接收一段**有返回值的函数体**，不是完整 C# 文件。不要在规则文本中写 using、类或函数声明。语言范围通过 `CRulesSyntax.Version` 查询，当前为 `1.0`；它不是“完整支持 C# 9”。宿主 SDK 支持的语法不自动成为规则语法。

本文按实际解析、表达式适配和测试覆盖整理。每种语法都受编译签名、可见类型、成员审计、数值策略和资源限额约束；表达式类型绑定主要来自 DynamicExpresso 的公开 API。

## 1. 支持总表

| 类别 | 当前支持 |
| --- | --- |
| 文本 | 分号、空白、换行、单行/块注释、普通字符串/字符 |
| 声明 | var、带初始化值的显式类型声明、const 只读绑定、局部作用域 |
| 类型 | 基础类型、可空值类型、引用类型末尾 ? 注解、可见对象/枚举、数组与封闭泛型 |
| 表达式 | 属性/字段/方法/索引访问、转换、算术、比较、布尔、三元、空值合并 |
| 赋值 | 局部 =、局部及字典索引的 +=/-=/*=、/=、%=、字典索引 = |
| 控制流 | if/else/else if、单行分支、常量 switch 语句与 switch 表达式、break、return |
| 构造 | 显式 new、对象成员初始化、有目标类型位置的 new() |
| 数组/List | 一维/交错数组、隐式数组、长度数组、List<T> 与裸 List 简写 |
| 字典 | Dictionary 构造、Add/索引初始化、读写、常用方法与有限 out 支持 |
| 动态数据 | ExpandoObject 点访问；普通字典索引；DataObject 有类型读取 |
| 异步 | 返回宿主 Task/ValueTask，由宿主等待；规则内部无 await |
| 实验项 | 显式开启后的嵌套 Lambda/LINQ，不属于默认严格模式 |

以下独立规则示例中，`amount/rate` 为 decimal，`enabled` 为 bool，`level` 为 string；需要 `ctx` 时它是含 Amount、IsVip 属性的上下文。示例会标明特殊返回类型；可见类型与签名配置见 [构造与执行](构造与执行.md)。

## 2. 文本、分隔与字面量

普通声明、赋值、调用和 return 后需要分号；代码块用花括号。关键字、变量、属性与动态字段均区分大小写。支持 `//` 单行注释和 `/* ... */` 块注释；注释会保留位置长度，以便诊断映射原始文本。字符串中的分号、花括号或注释字符不是语句边界。

<!-- rule:decimal -->
```csharp
// decimal 字面量使用 m；注释可跨行。
decimal total = amount * rate;
/* 根据配置决定折扣。 */
if (enabled) { total *= 0.9m; }
return total;
```

普通字符串支持上游识别的转义，字符使用单引号；数字可使用对应后缀，例如 100L、100U、100UL、1.25f、1.25d、100m。CRules 专门补充了科学计数法 float 的兼容处理，例如 `1e-3f`，但 DecimalOnly 下仍拒绝 float。

<!-- rule:string -->
```csharp
string text = "a; { /* literal */ }\n";
char tag = 'A';
return text + tag;
```

规则内部不支持插值字符串 `$"..."`、原始字符串 `"""..."""` 或预处理指令。逐字字符串 `@"..."` 虽能被边界扫描器识别，但当前上游解析存在已确认限制，不作为受支持的规则字符串形式。

## 3. var 与显式类型局部声明

每条声明只定义一个变量，而且必须初始化。var 在编译时推断**固定的静态类型**，不是动态变量。

<!-- rule:decimal -->
```csharp
var inferred = amount;
decimal explicitValue = inferred;
int count = 2;
long total = 100L;
bool active = enabled;
if (active) { explicitValue += count; }
return explicitValue + total;
```

基础类型关键词为 sbyte、byte、short、ushort、int、uint、long、ulong、float、double、decimal、bool、char、string、object。支持数组、上游可解析的封闭泛型和可见对象/枚举类型。nint/nuint 关键词不在当前清单中。

显式声明的左侧类型决定变量类型，初始化和后续赋值按隐式转换检查。`decimal x = 100;`、`byte x = 100;` 合法；`byte x = 256;`、`int x = 1.5;`、`decimal x = "100";` 不合法，需要显式转换的场景应自行写转换表达式。

以下写法分别拒绝，不应作为一条完整规则运行：

```csharp
decimal a;                     // 没有初始化。
decimal a = 1m, b = 2m;         // 一条声明多个变量。
var a = null;                  // 无法推断类型。
var a = new();                 // new() 没有目标类型。
```

## 4. const：执行期只读绑定

语法是 **`const 名称 = 表达式;`**，不是原生 C# 的 `const decimal 名称 = 常量;`。初始化表达式每次执行都会求值，可以使用输入、公开方法返回值或创建对象；它没有 C# 编译期常量折叠和常量转换的完整语义。

<!-- rule:decimal -->
```csharp
const factor = rate;
const initial = amount * factor;
return initial;
```

声明后不能对绑定使用 `=` 或复合赋值，也不能用作 out 目标。若绑定的是 List/字典/对象，绑定只读不代表对象不可变：可用的方法和字典索引写入仍可能修改内容。

## 5. 名称与作用域

输入和局部名称不可占用关键字、可见类型名称或 `__crules_` 前缀。局部不能遮蔽形参或仍可见的外层局部，不能在自身初始化表达式中读取自身。花括号创建局部作用域，退出后无法访问内部局部；每次 Execute 都重新初始化局部。

<!-- rule:decimal -->
```csharp
decimal result = amount;
{
    decimal adjustment = 2m;
    result += adjustment;
}
return result;
```

兄弟代码块可以各自声明同名变量。if/else 中声明局部时必须带花括号；`if(enabled) decimal x = 1m;` 拒绝。MaxLocals 统计整条规则中的局部声明，不是同时存活变量数量。

## 6. 普通表达式与数值转换

常见支持项如下，绑定与重载受上游实际能力约束，不承诺完整 C# 类型系统：

| 用法 | 例子 |
| --- | --- |
| 属性、字段与索引 | `ctx.Amount`、`result.Rank`、`values[0]`、`data["key"]` |
| 实例/静态方法 | `text.Contains("a")`、`Math.Round(value, 2, MidpointRounding.ToEven)` |
| 算术与符号 | `+ - * / %`、一元 `+ -`、括号 |
| 比较与相等 | `> >= < <= == !=` |
| 布尔和短路 | `!`、`&&`、`||` |
| 条件与空值合并 | `enabled ? 0.9m : 1m`、`optional ?? 1m` |
| 显式转换 | `(decimal)count`、`(decimal)customer.Amount` |

三元与短路只计算实际选中的分支。空值合并不把零、false 或空字符串当成 null。为兼容上游，CRules 还补充了命名 char/char? 操作数之间部分 `??` 数值提升；这不是对任意表达式进行完整类型重写。

<!-- rule:decimal -->
```csharp
decimal? optional = null;
decimal basis = optional ?? amount;
decimal factor = enabled ? rate : 1m;
return Math.Round(basis * factor, 2, MidpointRounding.ToEven);
```

除零、decimal 溢出等异常向外传播。decimal 自身也有有限范围与精度；除法和业务舍入应显式表达，不代表任意精度计算。

## 7. DecimalOnly 数值策略

默认关闭。开启后会审计整个表达式树，拒绝 float/double（包括可空类型和显式转换中的浮点子树）；算术结果必须为 decimal 或 decimal?，避免整数除法、溢出等被误当作十进制计算。

- 推荐 `amount / 3m`；`1 / 3` 不会被自动改写为 decimal。
- `return 1;` 可以隐式转换到 decimal；但 `return 0.1 + 0.2;` 不会因返回类型是 decimal 而变成十进制运算。
- `(decimal)0.1` 仍含 double 子树，会被拒绝；写 `0.1m`。
- 动态输入先显式转成 decimal，再做算术，见动态数据章节。

这是宿主配置，不是新增规则关键字。需要整数路由、字符串拼接或 float 运算的规则，不应套用不适合其语义的 DecimalOnly 配置。

## 8. 局部赋值与复合赋值

<!-- rule:decimal -->
```csharp
decimal value = amount;
value = value * rate;
value += 2m;
value -= 1m;
value *= 3m;
value /= 2m;
value %= 10m;
return value;
```

`+=`、`-=`、`*=`、`/=`、`%=` 支持局部变量及可写字典索引；字符串局部支持合法的 `+=` 拼接。禁止修改形参绑定、const 绑定或普通输入对象属性；表达式内部的赋值（例如 `return (x = 1);`）不开放。数组/List 索引写入也不在当前写入目标清单中。

小整数复合赋值支持现有规则允许的回转转换，例如非 DecimalOnly 下 `var x = (byte)250; x += 10; return x;` 得到 4。`var x = 1; x += 1.5;` 和 char 加 int 则被拒绝；这与完整 C# 复合转换并不完全一致。字符串拼接、小整数行为均有单独回归，不能泛化为任意隐式窄化。

## 9. if / else / else if

<!-- rule:decimal -->
```csharp
if (amount <= 0m) return 0m;
if (ctx.IsVip) {
    return amount * rate * 0.9m;
} else if (enabled) {
    return amount * rate;
} else {
    return amount;
}
```

条件需要可绑定为 bool。支持单条语句分支和花括号块，else 绑定最近的未匹配 if。不是强制“最后一条文本必须是 return”：只要可证明所有可达终止路径都返回，两个分支分别 return 即合法。

简单布尔常量及部分 `!`、`&&`、`||` 常量组合参与可达性分析；这不是完整 C# 常量求值器。条件为运行时值时，不能因为测试输入总为 true 就省略另一条返回路径。

## 10. switch 语句

<!-- rule:decimal -->
```csharp
decimal factor = 1m;
switch (level) {
    case "gold":
    case "platinum": factor *= 0.8m; break;
    case "silver": return amount * 0.9m;
    default: break;
}
return amount * factor;
```

- 支持常量 case、分组标签、default、嵌套 switch 和 break。
- 选择值支持字符串、整数、字符、枚举、bool、decimal 及适用的 Nullable<T>。
- 标签只允许字面常量/可识别常量转换与枚举常量，不能用宿主运行时方法求标签。常量必须能隐式转换到选择值类型，拒绝重复标签、重复 default 和越界常量。
- 每个有语句的分支必须以 return 或 break 结束，不能贯穿；分组空标签不属于贯穿。分支拥有独立局部作用域。
- break 只退出最近的 switch，不是函数返回。含 break 或可能未命中的 switch 后仍需返回。
- 常量选择值可只分析实际分支；bool/bool? 覆盖 true、false 及适用的 null 后可证明闭合。枚举已命名成员不能代表全部可能值。

## 11. switch 表达式

<!-- rule:decimal -->
```csharp
decimal factor = level switch {
    "gold" => 0.8m,
    "silver" => 0.9m,
    _ => 1m,
};
return amount * factor;
```

支持作为整条 return、局部初始化或赋值的值。最后必须有 `_ => ...` 默认分支，可有尾逗号；选择值只求值一次，仅执行选中的分支。分支结果按目标类型/上游条件绑定规则统一。

不支持模式、when、or、关系/属性/列表模式或解构，也不承诺将 switch 嵌入任意算术、方法实参或 Lambda。重复常量和默认分支之后还有分支会被拒绝。

## 12. return、null 与可达路径

return 必须带表达式并以分号结束，表达式需能隐式转换到声明的返回类型。缺少返回路径为 CRL2005；已终止路径后的语句为 CRL2006。没有隐式末表达式返回，没有无值 return。

<!-- rule:nullable -->
```csharp
decimal? result = null;
if (enabled) { result = amount * rate; }
return result;
```

引用类型和 Nullable<T> 可以直接返回 null，也可返回值为 null 的输入、属性或局部变量。非可空 decimal/int/bool 等返回类型拒绝 null；nullable 数值不能隐式解包成非可空数值。

引用类型局部声明末尾 `?` 作为注解接受，不提供 C# nullable 流分析/警告；`Decision` 与 `Decision?` 的运行时 Type 相同，都可返回 null。三元 nullable 数值分支必要时显式标注，例如 `return enabled ? (decimal?)null : 2m;`。

顶层结果支持物化数组/List/字典，不开放任意 IEnumerable、Delegate、Expression 或 void 签名。构造接口目标时需要显式写具体类型。

## 13. 对象与目标类型 new()

以下假定 `Decision` 有公开可写 Amount 属性，返回类型为 Decision，因而类型名自动可见。

<!-- rule:decision -->
```csharp
Decision result = new() { Amount = amount * rate };
return result;
```

也支持 `new Decision()`、`new Decision { Amount = ... }`、`return new() { ... };`、有参数的 `new(...) { ... }`。目标类型 new() 可用于直接返回、显式类型局部初始化、字典赋值和已知目标类型的集合元素/成员值。

初始化值按目标成员类型检查；公开可写属性（含 init）和实例字段可初始化，重复成员、只读字段/属性、索引属性作为普通成员、未知名称和错误类型拒绝。构造先于成员值，成员值和 setter 按源码顺序执行一次；编译过程不运行构造或业务 getter/setter。

object、接口、抽象类不接受当前省略类型的 new()，应明确构造具体类型。默认值类型构造（例如 `decimal? v = new();`）有专门适配。匿名对象、required 成员完整性检查、任意方法实参/三元/括号内部的目标类型 new() 不在完整承诺内。普通对象属性的后续 `result.Amount = ...;` 仍不开放，需通过初始化器或宿主方法表达。

## 14. 数组

<!-- rule:array -->
```csharp
decimal[] values = new[] { amount, rate };
return values;
```

支持 `new int[] { 1, 2 }`、`new[] { 1, 2 }`、`new int[length]`、`new int[2] { 1, 2 }` 和一维交错数组。显式长度带初始化时必须是匹配元素数量的常量；普通长度数组在执行时按 .NET 语义创建，负长度会失败。

隐式数组必须有非空元素列表，按当前共同元素类型算法绑定，null 元素不能单独确定类型。显式数组逐元素检查转换，创建顺序与异常有差分回归。多维数组、集合表达式 `[1, 2]`、展开 `..values` 不支持。

适配覆盖整条返回值、局部初始化/赋值和成员值等递归传入解析器的位置，不承诺嵌入任意其他表达式的完整数组语法。交错数组应显式构造每层所需的数组。

## 15. List

返回类型为 List<decimal>，或宿主已补充 List<> 时：

<!-- rule:list -->
```csharp
var a = new List<decimal>() { amount, rate };
List<decimal> b = new() { a[0], 2m };
b.Add(3m);
return b;
```

支持读取索引、公开方法调用、空列表、尾逗号和单实参加花括号元素（例如 `{ { 1m }, { 2m } }`）。方法调用受成员审计；List 索引直接赋值不在当前支持范围。

CRules 还特意支持下面的**专有简写**，不属于标准 C#：

<!-- rule:list -->
```csharp
List values = new() { amount, rate };
return values;
```

通过当前隐式数组共同元素类型规则推断 List<T>，编译时不执行元素。空列表、全是无类型 null 或无法找到共同类型时拒绝，应改为明确 List<T>。List<> 需由签名自动可见或由 ReferencedTypes 补充；`List a = null;`、`List a = new();` 没有足够信息，拒绝。

## 16. Dictionary 构造与两种初始化器

下面返回 Dictionary<string,decimal>，相关类型自动可见。

<!-- rule:dictionary -->
```csharp
var source = new Dictionary<string, decimal>() {
    { "amount", amount },
    { "rate", rate }
};
Dictionary<string, decimal> result = new(source) {
    ["rate"] = 0.9m,
    ["extra"] = 1m,
};
return result;
```

支持 var + 显式构造、完整显式声明、左侧类型 + new()，以及容量/拷贝/比较器等能被上游绑定的标准重载。签名外的 StringComparer 等类型需额外注册。省略键/值类型的裸 `Dictionary a = ...` 不支持。

| 初始化形式 | 实际操作 | 重复键 |
| --- | --- | --- |
| `{ { key, value } }` | Add(key, value) | 执行时抛 ArgumentException |
| `{ [key] = value }` | 索引 setter | 后面的值覆盖前面的值 |

同一个初始化器不能混合两种元素。键和值按各自目标类型绑定；空键保持字典的异常，null 值由 TValue 决定。支持嵌套对象/List/字典和目标类型 new()：

<!-- rule:nested -->
```csharp
return new() {
    ["items"] = new() { new() { Amount = amount } },
};
```

这个例子的返回类型是 Dictionary<string,List<Decision>>。不支持索引器已有集合的省略 new 写法 `[key] = { ... }`，也不承诺任意第三方字典初始化器。

## 17. 字典读写、方法调用和 out

<!-- rule:dictionary -->
```csharp
Dictionary<string, decimal> result = new() { ["amount"] = amount };
result["amount"] *= rate;
result.Add("extra", 1m);
result.TryAdd("extra", 2m);
if (result.ContainsKey("extra")) { result.Remove("extra"); }
if (result.TryGetValue("amount", out var value)) {
    result["calculated"] = value;
}
return result;
```

Count、Keys、Values、ContainsKey、ContainsValue、Add、TryAdd、Remove、Clear 等公开成员可用。独立方法调用可忽略返回值；不能独立写一个无用途的算术表达式。可写 Dictionary/IDictionary 等泛型字典允许索引 = 和五种复合赋值，接收者、键、右值各求值一次；IReadOnlyDictionary 不可写。

缺失键读取抛 KeyNotFoundException。对输入字典写入会修改调用方对象，若要副本应显式 `new(ctx)`；只读参数绑定/const 不冻结字典。索引 getter、setter 和 Add 等操作都经过成员审计。

TryGetValue 和 Dictionary.Remove 的双参数重载支持：

| 写法 | 要求 |
| --- | --- |
| `out value` | 已初始化、类型完全一致的可写局部，不可为形参或 const |
| `out var value` | 新建当前块局部，不能与可见名称冲突 |
| `out _` / `out var _` | 丢弃结果；已有名为 _ 的局部时按实现的绑定规则处理 |

直接调用、if 条件中的 out var 可在当前块后续使用。短路/三元表达式内的 out var 暂不支持，需改为先初始化，再 out：

<!-- rule:decimal -->
```csharp
Dictionary<string, decimal> data = new() { ["amount"] = amount };
decimal value = 0m;
bool found = enabled && data.TryGetValue("amount", out value);
return found ? value : 0m;
```

短路未调用时保留原 value。一般宿主方法的 ref/out、不初始化的 out 显式类型声明等不属于这项字典专用适配。

## 18. 动态变量与动态数据

### ExpandoObject：直接动态点访问

动态能力来自输入的运行时对象；不需要、也不支持在规则里通过 `dynamic x = ...` 声明新的动态绑定变量。普通 var 仍推断静态类型。

<!-- host:dynamic -->
```csharp
using CRules;
using System.Dynamic;

dynamic customer = new ExpandoObject();
customer.IsVip = true;
customer.Amount = 100m;
customer.Rate = 0.9m;
var executable = new RuleCompiler(new CompilerOptions { DecimalOnly = true })
    .Compile<ExpandoObject, decimal>(
        "if(ctx.IsVip) return (decimal)ctx.Amount * (decimal)ctx.Rate; return (decimal)ctx.Amount;")
    .RequireExecutable();
Console.WriteLine(executable.Execute((ExpandoObject)customer)); // 90.0
```

字段缺失或类型不符在执行时失败。DecimalOnly 会检查 ExpandoObject 中的浮点值，动态结果也会检查；动态算术先显式转换成 decimal，不能依赖最终返回类型纠正动态算术。动态输入不复制/冻结。

配置 IsMemberAllowed 后，动态成员无法静态审计，会被拒绝。自定义 DynamicObject 不在已验证范围；字典/JsonElement 不会自动转换为点访问。AOT 的完整动态能力不能从普通 JIT 结果推断，见 [NativeAOT支持](NativeAOT支持.md)。

### DataObject：不可变、有类型读取

<!-- host:data -->
```csharp
using CRules;

var data = DataObject.FromJson("""{"rate":0.9,"customer":{"tier":"vip"}}""");
var executable = new RuleCompiler().Compile<DataObject, decimal>(
    "return ctx.RequireDecimal(\"rate\") * 100m;").RequireExecutable();
Console.WriteLine(executable.Execute(data)); // 90.0
```

DataObject 是可选通用 JSON 快照，不是规则参数的强制类型。支持 FromJson(string)、FromJson(JsonElement)、FromDictionary(IReadOnlyDictionary<string,object?>)、Empty；创建时复制快照，外部字典修改或 JsonDocument 释放不影响它。

| 读取 API | 返回 | 缺失/JSON null | 类型不符/超范围 |
| --- | --- | --- | --- |
| GetString | string? | null | DataReadException |
| GetBoolean | bool? | null | 同上 |
| GetInt64 | long? | null | 同上，不截断小数 |
| GetDecimal | decimal? | null | 同上 |
| GetObject | DataObject? | null | 同上 |
| RequireString/Boolean/Int64/Decimal/Object | 对应非空类型 | DataReadException | 同上 |

`GetState` 区分 Missing、Null、Value；Contains 对显式 null 返回 true，IsNull 对缺失返回 false。键区分大小写，点号是普通键字符；嵌套对象用 RequireObject/GetObject 继续读取，不自动按路径展开。类型错误不是缺失，不会被 `?? 默认值` 吞掉。

默认上限为 262144 UTF-8 字节、深度 16，根必须是对象，拒绝重复键（包括嵌套对象）。没有数组枚举 API，不把字符串强转数值/布尔。GetDecimal 遵循 System.Text.Json 的 decimal 精度和舍入行为，超精度不代表任意精度；FromDictionary 会先序列化，其任意对象序列化行为由宿主承担。DataReadException 公开 Key、ExpectedType、State。

## 19. 宿主方法、异步与实验 Lambda

公开的实例/静态方法可出现在表达式中，也可独立作为调用语句；代码不能声明新方法。返回 Task/ValueTask 的宿主调用直接 return，交给 Execute/ExecuteAsync 的外层调用者等待，规则字符串内部没有 async/await。

严格模式拒绝嵌套 Lambda；只有显式设置 `AllowRuntimeLambdaBinding = true` 才可尝试如下规则：

```csharp
// 实验模式；假定 ctx.Items 是 decimal[]，返回 decimal。
var threshold = 2m;
return ctx.Items.Where(x => x > threshold).Sum();
```

已有 JIT 测试覆盖捕获局部变量，但可能涉及执行时委托绑定及额外分配；不是标准无运行时绑定保证，更不是 AOT 通行证。

## 20. 明确不支持的语法

| 类别 | 当前未开放 |
| --- | --- |
| 声明 | 未初始化、同条多变量、原生 typed const、dynamic 局部、类型/函数/局部函数声明 |
| 流程 | for/foreach/while/do、continue、goto、try/catch/finally、throw 语句、yield |
| 资源与异步 | using、lock、async/await、任意 ref/out、unsafe/指针 |
| 表达式 | ++/--、空条件 ?.、集合表达式/展开、模式匹配、插值/原始字符串 |
| 赋值 | 形参绑定、普通对象属性/字段、数组/List 索引、嵌入表达式的赋值 |
| 构造 | 匿名对象、无目标 new()、省略 Dictionary 键值类型、任意第三方初始化器 |

不支持的代码通常返回编译诊断，不会自动切换成 Roslyn 或更高版本 C# 解析。已知上游/适配缺陷、成员与资源边界集中在 [已知问题](已知问题.md)。
