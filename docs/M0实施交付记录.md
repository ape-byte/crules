## 代码范围

`CRules.Abstractions` 定义源码、诊断、编译结果和执行模式；`CRules` 管理语句边界、词法作用域、控制流、上游 adapter 和表达式树组合。

表达式解析和类型检查仍全部交由 DynamicExpresso。局部变量由 ParameterExpression 直接绑定，外层只 Compile 一次。严格 JIT 标量路径没有逐语句解析、反射分派或变量字典调度。AOT 解释模式不继承这些性能保证。

## 后续实施顺序

3. 完成宿主精确成员白名单、运行位置诊断、资源约束和完整数值转换审计。
4. 实施有界缓存、single-flight、原子规则集热更新与回滚。
5. 对真实业务流量建立 SLO，并扩大目标平台和长时间稳定性验证。

本次交付验证了路线并提供可执行骨架；上述后续事项没有以 M0 或性能基准通过的名义提前验收。
