# 快速开始

CRules 适合频繁变化的计算、条件判断和结果选择规则：宿主固定输入/输出契约，规则代码可在加载时编译并重复执行。口号“以不变应万变”指以一种代码配置方式承载不同规则需求。

## 1. 引用项目

当前仓库目标框架为 .NET 10，SDK 固定见根目录 [global.json](../global.json)。在自己的 .NET 10 项目中引用核心项目；下面以仓库根目录中的 `MyApp` 为例：

```powershell
dotnet add MyApp/MyApp.csproj reference src/CRules/CRules.csproj
```

这里只说明源码项目引用，不假设已有正式 NuGet 发布版。公开类型位于 `CRules` 命名空间；核心依赖 DynamicExpresso.Core，Jint 和 Roslyn 只用于基准或测试。

## 2. 第一条规则

以下是完整宿主程序，可放入引用 CRules 后的控制台项目 `Program.cs`：

```csharp
using CRules;

var compiler = new RuleCompiler(new CompilerOptions { DecimalOnly = true });
var executable = compiler.Compile<PriceContext, decimal>(
    """
    decimal total = ctx.Amount * ctx.Rate;
    if (ctx.IsVip) { total *= 0.9m; }
    return Math.Round(total, 2, MidpointRounding.ToEven);
    """,
    name: "CalculatePrice").RequireExecutable();

decimal first = executable.Execute(new PriceContext(100m, 0.8m, true));
decimal second = executable.Execute(new PriceContext(100m, 0.8m, false));
Console.WriteLine($"{first:F2}; {second:F2}"); // 72.00; 80.00（小数分隔符受宿主文化影响）

public sealed record PriceContext(decimal Amount, decimal Rate, bool IsVip);
```

`PriceContext` 是普通 C# 类型，`ctx` 是默认形参名。返回类型由 `decimal` 泛型实参确定，必须明确提供。输入、输出类型会自动注册，例子不需要额外配置 `ReferencedTypes`。

原始字符串 `"""` 是宿主 C# 用来保存文本的语法。字符串内部的规则只支持 [CRules Syntax 1.0](%E8%AF%AD%E6%B3%95%E5%8F%82%E8%80%83.md)，不是完整 C#。

## 3. 不构造上下文，直接传多个参数

```csharp
using CRules;

var executable = new RuleCompiler()
    .Compile<Func<decimal, decimal, Dictionary<string, decimal>>>(
        """
        var source = new Dictionary<string, decimal>() {
            { "amount", amount },
            { "rate", rate }
        };
        source["amount"] *= rate;
        return source;
        """,
        ["amount", "rate"])
    .RequireExecutable();

Dictionary<string, decimal> result = executable.Execute(100m, 0.9m);
Console.WriteLine(result["amount"]); // 90.0
```

输入名称用于绑定代码中的变量；执行时按声明顺序传值。字典返回类型已由委托签名提供，不需要再次注册。

## 4. 处理编译失败

```csharp
var compilation = new RuleCompiler().Compile<decimal, decimal>("return missing;");
if (!compilation.Success) {
    foreach (var error in compilation.Diagnostics) {
        Console.WriteLine($"{error.Code}: {error.Line}:{error.Column} {error.Message}");
    }
}
```

源码错误通常返回诊断；`RequireExecutable()` 会把失败转为异常。执行阶段的除零、空引用或宿主方法异常向调用方传播，不自动返回零。

## 5. 接下来

- 编译一次、缓存 executable，重复执行；每次调用创建独立的局部变量。
- 每条可达结束路径都需要 `return`；完整 if/else 分别返回是合法写法。
- 需要动态数据、运行时 Type 或异步返回，见 [构造与执行](%E6%9E%84%E9%80%A0%E4%B8%8E%E6%89%A7%E8%A1%8C.md)。
- NativeAOT 必须显式选择 `Interpreted` 并保留宿主元数据，见 [NativeAOT支持](NativeAOT%E6%94%AF%E6%8C%81.md)。
- CRules 当前没有内置规则仓库、版本管理或发布流程；这些由宿主实现。
